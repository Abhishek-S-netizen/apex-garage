# APEX — Performance Model Car Collection Suite (React Edition)

A high-performance automotive collection management desktop suite engineered with the aesthetics of hypercar telemetry clusters (Porsche Motorsport, AMG Petronas, Ferrari Atelier).

## Features
- **Cockpit Command Center**: 60 FPS HTML5 Canvas mechanical-digital dials (Fleet Capacity Tachometer, Marques Dial, Makers Dial) with 3.2s S-curve rev-sweep calibration, optical glass binnacle shading, and flipped bento layout.
- **Showroom Floor**:
  - **Stage 1 (Marque Curator Gateway)**: Marque cards with model counts and scale filters.
  - **Stage 2 (3D Cover Flow Carousel Ring Floor)**: Hardware-accelerated 3D coverflow ring powered by Swiper React with coverflow physics, keyboard navigation, inspection, and favorites.
- **Master Registry**: Inventory audit table with sorting, search, and JSON export.
- **Peg Hunt & Grails**: Priority-tiered watch radar (Grail, High, Normal) with target acquisition pricing.
- **Libraries Manager**: Global automotive marques and diecast manufacturers database.
- **Atelier Garage Studio Drawer**: Live sliders for surface opacity (15%–100%), Apple corner curvature (6px–36px), eyebrow contrast, and automotive color swatches.
- **Modals & macOS Dock**: Vehicle intake modal, deep performance specs dossier inspection sheet, and floating macOS-style dock with hotkeys.

## Color Scheme & Visual Token System
- **Void & Base**: Warm Obsidian (`#1A1819` / `#121011`)
- **Metallic Borders & Secondary Telemetry**: Champagne Sand (`#BDA794`)
- **Signature Performance Accent**: Atelier Carmine Red (`#9F3E3E`) with bright highlights (`#C35656`)
- **Card Surfaces**: Crisp obsidian glass (`rgba(26, 24, 25, 0.78)`) with zero muddy blurs
